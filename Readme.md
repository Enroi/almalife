# Сервис обработки информации на основе Apache Spark

## Состояние проекта

Находится в разработке.
На данном этапе создается ETL часть.

## Описание

Основная идея проекта реализовать ETL средствами [Apache Spark.](https://spark.apache.org/).
Параметры подключения к источникам и месту назначения загруженных и измененных данных описываются в файлах конфигурации.

## Конфигурации

Проект дает возможность создавать и управлять конфигурациями рассчетов в формате yaml файлов без необходимости перезапуска базовой части.
Конфигурация описана в [базовом примере](api_server/etl/configs/base_example.yaml)

## Отображение результатов

Результаты преобразований данных отображаются с помощью [Apache Superset](https://superset.apache.org/)

## Запуск

При желании проверить работу проекта необходимо:

1. Запустить инфраструктуру через [docker-compose](docker-compose.yaml)
2. Запустить примеры преобразований. Самый простой способ это запустить на выполнение файл [transformer.py](api_server/etl/transformer.py)
