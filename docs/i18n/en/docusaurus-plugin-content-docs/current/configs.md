# ETL Process Configurations

The main purpose of this project is to create a platform for the simplest possible use of Apache Spark's data transformation capabilities without the need to write boilerplate code. Configurations for basic transformations are described as YAML files.\
The structure and a basic configuration example are described in the [base example file](https://github.com/Enroi/almalife/blob/main/api_server/etl/configs/base_example.yaml).\
An example of working with databases via JDBC is shown in the [XML transformation example](https://github.com/Enroi/almalife/blob/main/api_server/etl/configs/xml_to_db.yaml).
