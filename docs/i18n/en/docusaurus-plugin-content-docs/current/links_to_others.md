# Related Projects

## Surrogate Key Service

Transformation processes often need to reference external data that has not yet been obtained. The "Surrogate Key Service" project is used to reference external data for which complete information has not yet been received.

## Services with the Same Technology Stack

This project is built on the same technology stack as several other projects, with which Almalife can be easily combined and/or integrated.

### Machine Learning Service Based on Apache Spark

The [py-spark-ml-test-1](https://github.com/Enroi/py-spark-ml-test-1) project makes it possible to find dependencies between elements of datasets (tables).

### Service for Distributing Values Across Related/Child Elements

The [Graph-Costs](https://github.com/Enroi/Graph-Costs) project demonstrates how, using Apache Spark and a machine learning library, to solve the problem of distributing amounts across dependent/child/related elements using the [graphframes](https://github.com/graphframes/graphframes) library.
