# Конфигурации ETL процессов

Основной смысл данного проекта состоит в создании платформа максимально простого использования возможностей Apache Spark для преобразования данных без необходимости написания шаблонного кода. Конфигурации базовых преобразований описываются в виде yaml файлов.\
Структура и базовый пример конфигурации описан в [базовом файле примера](https://github.com/Enroi/almalife/blob/main/api_server/etl/configs/base_example.yaml).\
Пример работы с базами данных через JDBC показан в [примере XML преобразования](https://github.com/Enroi/almalife/blob/main/api_server/etl/configs/xml_to_db.yaml).
