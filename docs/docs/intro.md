# Краткое описание

Основная идея проекта реализовать ETL средствами [Apache Spark.](https://spark.apache.org/).\
В проект заложены все возможности преобразования данных средствами [Apache Spark.](https://spark.apache.org/).\
Дополнительно предусмотрена возможность создавать свои собственные процедуры обработки данных. Это позволяет реализовывать бизнес логику стандартными средствами ETL\
Параметры подключения к источникам и месту назначения загруженных и измененных данных описываются в файлах конфигурации.
