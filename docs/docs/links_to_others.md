# Связи с другими проектами

## Сервис суррогатных ключей

В процессах преобразования часто необходимо ссылаться на внешние данные которые еще не получены. Для связи с внешними данными, полная информация о которых еще не получена используется проект "Сервис суррогатных ключей".

## Сервисы с одинаковой технологической базой

Данный проект построен на одинаковой технологической базе с несколькими другими проектами, с которыми Almalife может быть легко объединен и/или интегрирован.

### Сервис машинного обучения (Machine Learning) на базе Apache Spark

Проект [py-spark-ml-test-1](https://github.com/Enroi/py-spark-ml-test-1) позволяет находить зависимости между элементами наборов данных (таблиц).

### Сервис распределения значений по связанных/дочерним элементам

Проект [Graph-Costs](https://github.com/Enroi/Graph-Costs) показывает как с помощью Apache Spark и библиотеки машинного обучения решить задачу распределения сумм по зависимым/дочерним/связанных элементам с помощью библоитеки [graphframes](https://github.com/graphframes/graphframes).
